# Dataset provenance

Use `water_potability.csv` from [Water Quality by Aditya Kadiwal on Kaggle](https://www.kaggle.com/datasets/adityakadiwal/water-potability), the dataset linked in the original presentation. Download it from that page and extract the CSV into this directory. The raw dataset is not redistributed in this repository.

For the companion run recorded on 2 November 2026, the CSV contained 3,276 rows and ten columns. SHA-256 of the exact CSV bytes:

`904004bde729bfe3d2e195f46343bceead09e32a0eb95bb8184e7e20e029b2bf`

Nine physicochemical measurements are used as features; `Potability` is excluded. The source may change, so compare the checksum when comparing runs. Dataset observations have no verified geographic interpretation in this project. Cluster IDs are not validated safety classes.
